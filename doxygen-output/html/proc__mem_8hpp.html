Process memory I/O via /proc/<pid>/mem (进程内存 I/O)

Unified low-level read/write interface for target process memory. Used by core.scanner, scan.engine, and scan.filter.

Provides minimal read/write capabilities using pread/pwrite on /proc/<pid>/mem. Requirements:

  • Sufficient privileges (root or CAP_SYS_PTRACE)
  • Does NOT auto-attach/detach ptrace (caller manages debugging policy)
  • Single fd open/reuse + one-shot convenience functions
